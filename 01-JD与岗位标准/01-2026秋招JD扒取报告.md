### 1.1 AI 产品经理线

**样本 A｜彩讯股份 · AI 产品经理（2026 届校招）** — 来源：richinfo.cn/jobs/campus/106

- 职位描述：对接行业头部大客户，负责 AI 产品从场景定义、方案设计、MVP 落地到商业化的全流程。
- 岗位职责：场景定义与需求分析；编写高质量 PRD 并与研发完成 MVP 落地；对接头部大客户，把客户需求转化为产品方案；跟踪产品数据持续优化；参与商业化推广与运营。
- 任职要求：2026 届本科及以上；**理解 LLM/RAG/Agent 技术边界**；**客户语言与技术语言双向沟通**；**具备 Harness 架构思维，能设计可扩展的产品方案**；ToB/SaaS 产品实习优先；**独立撰写 PRD、自研小程序/APP 经验优先**；商业竞赛或创业经历优先。
- 薪酬：20–35 万/年。

**样本 B｜彩讯股份 · AI 产品经理（大模型/智能体方向，2027 届）** — 来源：richinfo.cn/jobs/campus/61

### 1.2 FDE（Forward Deployed Engineer / 前线部署工程师）线

**样本 G｜腾讯 · 前线部署工程师（社招，产品职业类别）** — 引自 36 氪 2026-08-29 报道对其 JD 的整理

- 学历：CS / 软件工程 / 数学 / 物理 / AI 等理工科本科及以上；经验：3 年以上工程或 toB 交付。
- 技术栈：各类 AI 应用技术栈、各类 Agent 产品，熟练 **RAG、Prompt、模型选型、Harness、微调、Skills、MCP、Multi-Agent** 等术语与实践。
- 职责：进客户现场，把模糊业务需求做成可上线的 AI 系统，推动客户真正用起来，**对交付效果和 ROI 负责**。
- 加分项：自己动手搭过 AI Agent 工具项目。

**样本 H｜字节 · AI FDE 工程师（研发类别；另有 FDE 实习生属销售支持类别）** — 引自中新网 2026-06-05 对其 JD 的整理

- 本科及以上，计算机/通信/AI 相关优先；**扎实编程基础（Python/Java），能独立完成代码开发与调试，具备全栈开发能力**；
- 熟悉大模型技术原理，**掌握大模型效果与性能评估方法，熟悉各类 Post-Training 技术**；熟悉大模型相关产品 API 调用。

**样本 I｜Wipro · Forward Deployed Engineer** — 来源：careers.wipro.com

- 5 年以上软件/云/DevOps/SRE/AI-ML 工程经验；Python 强，做过 AI/GenAI 应用；
- **LangChain、LangGraph、Agentic AI 框架、LLM 技术**实操；有生产环境部署 AI 方案经验。

**样本 J｜Anthropic FDE 面试流程（五关）** — 引自 36 氪对 Reddit 面试指南的整理

1. HR 初筛：为什么选择驻场而不是传统研发（动机）。
2. 技术场景：围绕 Claude + MCP 等工具链的部署推演，重点考**上下文窗口管理、超长上下文不可靠如何兜底**。
3. 编码轮：算法 + 针对性实战（额度限制器、重试排队、小型数据库连接器、任务调度系统）。
4. **客户模拟轮（淘汰率最高，约六成倒在这里）**：面试官扮演不懂技术的高管与挑剔的架构师，**不许开编辑器，全靠提问完成需求发现**。
5. 价值观轮：使命与商业冲突、上级压力下的选择。

**样本 K｜吴恩达 AI 工程技能图谱（基于大量 JD + 专家访谈）** — 引自 36 氪同篇

- 四项技能：构建与部署 AI 应用、软件工程基础、使用 Coding Agent、Shaping the Build（理解业务与客户目标、参与决定做什么）。
- 第一项拆六模块：**大模型基础 / 用数据为模型提供上下文 / Agent 系统 / 评测驱动开发 / 生产运维 / 机器学习基础**。

## 4. 面试口径（照着准备，别照着想象准备）

- **"能演示的作品、评测口径、负责过的指标"是产品岗三件套**（36 氪 2026-11 对转岗者的建议，来源见下）。没有 AI 项目就自己做一个 —— 这正是本项目要产出的东西。
- FDE 的客户模拟轮：**不许写代码，只允许提问**。所以要练的是"需求发现脚本"，不是刷题。
- 编码轮偏工程小系统（限流器、重试队列、连接器、调度器），不是纯 LeetCode。

## 5. 针对你个人背景的定位建议（生物信息 × 医疗 × B 端）

- 你的相对优势：懂医疗数据的脏、懂临床/科研场景的语言、有生信的数据处理底子。
- 你的相对劣势：排斥纯代码开发 → **不要走"训练/算法工程师"路线**，走"AI 产品（医疗 B 端）+ FDE-lite"。
- 推荐岗位排序：① 医疗/医药/器械企业的 AI 产品经理（B 端）→ ② AI 解决方案/售前（FDE 的前半段）→ ③ 大厂 FDE（需要补 C6/C7 到能独立部署）。
- 差异化作品集：**一个"医疗知识库问答 + 评测报告 + 部署上线"的完整交付**，比五个 demo 有用。本项目第 03/06/07/08 章正好拼出这个东西。
