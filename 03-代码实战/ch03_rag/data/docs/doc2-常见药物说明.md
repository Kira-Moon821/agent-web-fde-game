# 常见药物说明摘要

【布洛芬】布洛芬为非甾体抗炎药，常见不良反应包括胃肠道不适、头晕与皮疹。妊娠晚期禁用布洛芬，具体剂量以说明书或医嘱为准，本资料不提供剂量建议。

【对乙酰氨基酚】对乙酰氨基酚过量可导致肝损伤。成人单日总量一般不超过 2 克，服药期间应避免饮酒，肝功能异常者需医生评估。

【二甲双胍】二甲双胍常见不良反应为腹泻与腹胀，多出现在用药初期并可逐渐耐受。肾功能不全者需调整或停用二甲双胍。

【阿莫西林】阿莫西林属于青霉素类药物。使用前需确认过敏史，可能出现皮疹与腹泻，过敏反应需立即停药并就医。

【药物相互作用】非甾体抗炎药与抗凝药合用时出血风险增加。合并用药需医生评估，不得自行加药或停药。
