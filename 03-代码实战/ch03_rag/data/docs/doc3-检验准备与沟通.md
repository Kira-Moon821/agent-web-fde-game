# 检验前准备与结果沟通

【空腹要求】多数生化检验要求空腹 8-12 小时。空腹期间可以少量饮水，但需避免剧烈运动与饮酒，否则会影响血糖与肝酶结果。

【采样时间】激素类指标存在昼夜节律。建议固定采样时间，便于不同时间点结果横向比较。

【参考区间的含义】参考区间来自健康人群的统计分布。检验值超出参考区间不等于患病，需结合临床表现与其他检查综合判断。

【危急值】危急值指可能危及生命的检验结果。实验室发现危急值会立即电话通知临床，并按流程记录处理时间。

【报告解读边界】检验报告不能替代医生诊断。AI 解读仅提供信息整理与术语解释，不得给出诊断结论、预后判断或用药剂量。

【复查建议】轻度异常通常建议 2-4 周复查。观察指标趋势比单点数值更有意义，复查项目应由医生确定。
