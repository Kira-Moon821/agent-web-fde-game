# 肝功能与肾功能指标解读

【ALT 谷丙转氨酶】ALT 主要存在于肝细胞中，参考区间通常为 7-40 U/L。ALT 升高提示肝细胞受损可能，需结合 AST、胆红素等指标综合判断，单次轻度升高不等于肝炎。

【AST 谷草转氨酶】AST 参考区间通常为 13-35 U/L。AST 也存在于心肌和骨骼肌，因此剧烈运动后可轻度升高，需结合肌酸激酶判断来源。

【肌酐】血清肌酐参考区间成年男性约 57-97 μmol/L、女性约 41-73 μmol/L。肌酐升高提示肾小球滤过功能下降，但结果受肌肉量、饮食与检测方法影响。

【eGFR 估算肾小球滤过率】eGFR 由肌酐、年龄、性别计算得出。eGFR 低于 60 且持续三个月，提示慢性肾脏病风险，需要医生进一步评估。

【血钾】血钾参考区间 3.5-5.5 mmol/L。血钾高于 6.0 mmol/L 属于危急值，需要立即处理；标本溶血可造成假性升高，应先复查。

【尿素氮】尿素氮受饮食蛋白摄入影响较大，单次升高需结合肌酐与临床表现判断，不宜单独下结论。
