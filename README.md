目标在短期内产出合格产品：系统完善、测评流程规范、客户交互合理

本仓库是完整的自包含交付物：岗位标准 → 学习路线 → 逐章代码 → 章节闸门 → 学习网站 → 容器化部署。全部代码零第三方依赖（Python 标准库 + 原生 HTML/CSS/JS），断网可复现。

## 快速开始

```powershell

cd F:\doubao\project1-ai医疗大模型行业分析

# 2) 本地看学习网站
python -m http.server 8090 --directory 04-学习网站      # 打开 http://127.0.0.1:8090
```

### 2. 学习路线（`02-学习路线/`）

`00-路线总图与检验机制.md` 定死 8 章主线、依赖关系、每章工时，以及**一章一检验**的三层闸门：

- **L1 概念口试**：8 问，讲清 ≥6 且每问带一个反例才算过。
- **L2 代码闸门**：该章 `check.py` 全 PASS。
- **L3 交付物验收**：5 项 × 20 分，≥80 才解锁下一章。

另有「防自欺三条」：数字优先、反例优先、可复现。三层全过才能进下一关，这是这套路线和"看完视频就当学会"的分界线。

8 章：01 大模型基础与 API 工程化 → 02 提示工程与上下文 Harness → 03 RAG 全链路 → 04 Agent 与工具调用/MCP → 05 数据构造与后训练 → 06 评测驱动开发 → 07 全栈工程与交互层 → 08 生产部署运维与 FDE 交付。每章含岗位锚点（JD 原话）、开源项目索引（star 数为本次 GitHub API 实查）、常见坑。

### 4. 学习网站（`04-学习网站/`）

像素游戏风格的 8 关地图，纯静态、`file://` 可开。版式比例不是拍脑袋定的，参考了 8-Bit Aesthetic（8px 网格、低密度瓦片）、Kombai「Pixel Hollow」（固定视口）、Kombai「Pacman Arcade」（CRT 扫描线 + 8-bit 字型）、Pixelado（1280 最大宽 + 8px 节奏），最终定为 **主舞台 16:9 / 侧栏 3:4 / 移动端 9:16**，依据写在 `04-学习网站/README.md`。

交互是按"一章一检验"设计的：点开一关 → 勾选 L1/L2/L3 → 三项齐了「完成本关」才可点 → 通关后加 XP、升 LV、解锁下一关，进度可存档/读档。`preview.png` 是 1280 宽实机截图。

**闸门是真跑出来的**：页面通过 Nginx `/api/` 反代读取后端报告，`GET /api/gates` 返回 8 章 check.py 的实跑结果。瓦片通过时显示 `✓ 闸门`，侧栏显示 `闸门 8/8 PASS`，关卡弹层里是 `PASS 6/6 · 2.42s`。右上「校验」按钮会带着令牌调 `POST /api/gates/refresh`，在服务端重跑一遍（约 10–13 秒），结果立刻回到页面。`file://` 打开时自动降级为离线模式，不报错。

### 5. FDE 部署（`05-FDE部署/`）

双容器：`medai-api`（非 root、内置 HEALTHCHECK）+ `medai-site`（Nginx，带 `/healthz` 与安全头）。配套 `deploy / stop / rollback / healthcheck` 四个脚本与 `DEPLOY.md`（D1–D6 六段闭环、监控阈值、三条回滚触发线、移交清单、客户 IT 安全清单、正反两版单位经济）。

实测状态（2026-11-25）：两容器均 **Up (healthy)**；健康检查 **PASS 3/3**；冒烟 **PASS 5/5**；压测 8 并发 40 请求 **40/40 通过，P95 364.9 ms，QPS 129.7**。

`DEPLOY.md` 第 9 节记了三个真实故障（容器健康但宿主机连不上、压测全断连、镜像源失效），每个都写了根因与处置——这部分比"部署成功"的截图更有说服力，面试时可以直接当案例讲。

## 已知限制

- 模型层是确定性 Mock（`common/mock_llm.py`），用于验证工程链路与成本口径，不用于效果验收；接真实模型只需替换 `LLMClient` 的 provider。
- 站点与 API 已打通（同源 `/api/` 反代），但「校验」是同步执行，一次约 10–13 秒；并发点击会被 429 挡住，这是刻意的最小实现，不是缺陷。
- 页面上的绝对时间戳以浏览器本地时区为准；容器时钟可能与宿主机有偏差，耗时只认 `duration_s`。
- 压测容量为单机 `ThreadingHTTPServer` 水平，500+ 并发需换 uvicorn 多 worker。
